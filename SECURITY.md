# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **Netools**, please do NOT create a public issue. Instead, report it privately via GitHub Security Advisories or by contacting the maintainer at `azhar@netools.local`.

All security reports will be acknowledged within 48 hours, and patches will be released promptly.
